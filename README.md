# NeoMusic

Ton lecteur de musique dans NeoBase : playlists en ligne et hors ligne, imports (YouTube, SoundCloud, Deezer, Exportify), recommandations, thèmes qui se débloquent avec ton niveau, vinyle et spectre en pixel art, égaliseur, statistiques, succès, mini-lecteur qui reste visible quand tu changes d'onglet, et raccourcis clavier valables partout dans Windows.

Ta bibliothèque est la même que sur ton téléphone : elle est sauvegardée et synchronisée par NeoBase, et tes musiques déjà téléchargées restent là où elles étaient.

## Installer

Dans NeoBase : **NeoStore → À découvrir → NeoMusic → Installer**. À la première ouverture, NeoBase te demande l'accès complet (le lecteur utilise le moteur de téléchargement et les raccourcis de NeoBase). Ton ancienne NeoMusic laisse alors sa place au plugin : ses tuiles et ses raccourcis ouvrent le plugin.

Développer un plugin : voir le [SDK NeoBase](https://github.com/NDesumeur/neobase-sdk).
